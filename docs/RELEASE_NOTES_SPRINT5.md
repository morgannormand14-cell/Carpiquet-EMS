# Carpiquet EMS v0.5.0-alpha — Sprint 5

Sprint 5 introduces the Automation Engine.

Highlights:
- deterministic state machine;
- `disabled`, `safe_hold`, `idle`, `discharge` states;
- explicit safety gates;
- configurable minimum state hold;
- optional fallback automation policy;
- automation diagnostics;
- dedicated Automation dashboard view;
- simulation-only boundary preserved.
